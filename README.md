# Foundly – Campus Lost & Found Platform

Foundly is a campus-focused lost-and-found application for reporting, browsing, and managing lost/found items.

## Live Demo

Frontend: https://lost-and-found-brown-two.vercel.app/

Backend API: https://lost-and-found-api-iq69.onrender.com/

## Features

- Report lost items
- Report found items
- Upload item images
- Browse and search reports
- Edit, resolve, and delete item reports

## Tech Stack

**Frontend**
- React

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB Atlas

**Other Technologies**
- Cloudinary
- Gemini

**Deployment**
- Vercel
- Render
