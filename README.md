# Foundly – Campus Lost & Found Platform

Foundly is a campus-focused web application that helps students report lost and found items, discover potential matches, submit claims, communicate securely, and complete the handover and return process.

## Live Demo

Frontend: https://lost-and-found-brown-two.vercel.app/

Backend API: https://lost-and-found-api-iq69.onrender.com/

## Features

- User registration and login
- Report lost items
- Report found items
- Upload item images
- Intelligent item matching
- Notifications
- Claim submission and approval
- Secure real-time chat
- Handover scheduling
- Return confirmation
- Reward handling
- Authentication and access control
